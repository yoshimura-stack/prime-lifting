# PRIME / LIFTING LAB — Prototype V0.3.1

## V0.3.1 の変更

ボール中心と接触部位の中心の左右差から打球方向を決めます。中心ならほぼ垂直、左端なら左、右端なら右へ飛びます。横方向の影響は旧版の約4倍（足6.5、膝6.0、胸5.5、頭6.0、空中頭7.0）に変更しました。たとえば足の中心から右へ10ずれていれば、静止時の横速度は右へ65です。端ほど打上げ力が最大12%低下し、浅い弧になります。

調整パネルの各技「横への影響」で0〜12を変更可能です。config.jsのCONTACT_EDGE_LIFT_LOSSで端の高さ減衰を調整できます。旧設定による上書きを防ぐため設定保存領域を分けました。

軌道変更に合わせてランキングをV0.3.1の標準設定用に分離。以前の記録は削除せず別テーブルに保存しています。

## V0.2.1 の変更

膝リフティングの動きを改良しました。太ももを前へ持ち上げ、すねを下・後方に折り畳み、つま先を下げます。パンツの裾も太ももに追従し、腕でバランスを取ります。接触姿勢を約0.095秒保ち、全体0.34秒で滑らかに戻します。次の入力は従来と同じ間隔で受け付けます。

膝の接触中心だけ地面から54→72へ上げ、持ち上げた太ももに合わせました。左右それぞれで同じ動きになります。膝の打上げ力、判定半径、得点、他の技やスピンの設定はV0.2と共通です。見た目の詳細はconfig.jsのKNEE_ANIMATIONで調整できます。

## V0.2 の変更

1. **両足・両膝**: 左右に独立した判定を追加。ボール中心との距離で接触側を選択し、成功した側の足・膝を動かします。移動方向では切り替えません。画面右側は選手の左足、画面左側は選手の右足です。
2. **スピン高速化**: 1回0.52秒から0.30秒へ変更。約0.60秒で2回転でき、次の打球成功で2回分のボーナスが確定します。1打球間の保留上限を2回分に変更。回転中の打球不可・落球時の失効は維持しています。右クリック1回で1回転なので、完了後にもう一度右クリックします。回転中の追加クリックは予約しません。
3. **3D描画**: 立体の選手・ボール、実際の軸回転、ユニフォーム、芝、落ちる影、フェンス、見守る観客、ベンチ、木々を実装しました。固定カメラと練習場を維持しています。

旧版の保存設定で新しい回転時間が上書きされないよう、V0.2は別の設定保存領域を使います。旧版の設定データは削除しません。

## 操作

| 入力 | 動作 |
| --- | --- |
| A / D | 左右移動 |
| SPACE | ジャンプのみ |
| 画面内で左クリック | その瞬間の位置から FOOT / KNEE / CHEST / HEADER / JUMP HEADER を判定 |
| 画面内で右クリック | 回転 |
| F2 | 身体判定、ボール中心、過去の軌道を表示 |
| ESC | 一時停止 / 再開 |

3、2、1のカウントダウン後、60秒のスコアアタックが始まります。落球しても短い待ち時間のあと中央からボールが再投入されます。選手はそのままの位置なので、A/Dで取りに行ってください。画面からフォーカスが離れた場合は一時停止します。

最初は、降りてきたボールの下へ移動して、足の高さまで待って左クリックしてみてください。慣れたら膝や胸で拾い、滞空中に回転を入れます。F2は身体部位の高さを覚える練習に使えます。接触円は「ボール中心が入っている必要がある範囲」です。

## 入力と得点のルール

- 自動リフティング、吸着、選手位置補正はありません。
- SPACEは選手の縦速度だけを変更します。空中で頭の範囲にボールがある瞬間に左クリックして初めてJUMP HEADERになります。
- クリック時の距離を判定します。範囲外のクリックはMISSとなり、ボールの位置や速度を変更しません。クリック長押しで連打しません。
- 各技の判定円が重なる場合、中心までの距離を半径で割った値が小さい部位を使います。上昇中も実際の接触範囲なら打球できます。
- 打球間隔は暫定0.19秒。この間の再入力は無視し、入力予約や自動打球を行いません。
- 回転中は移動速度が20%になり、打球できません。ジャンプも回転完了を待つ必要があります。空中で回転することはできます。
- 一度打球したあと、回転を完了し、次の打球に成功すると回転ボーナスが確定します。回転だけでは加点しません。1打球間に最大2回分まで保留でき、落球で失います。
- 得点初期値はFOOT 100 / KNEE 150 / CHEST 200 / HEADER 250 / JUMP HEADER 500 / SPIN BONUS 300。原作の確定値ではありません。

## ゲームフィール調整

「調整パネル」では移動、加速・減速、ジャンプ、重力、回転時間、打球間隔、各技の打上げ力・判定半径・横方向の影響・得点を変更できます。調整中は一時停止し、再開ボタンで戻ります。

パネルの数値はブラウザのローカル保存を使います。保存が許可されない環境でもプレイ可能ですが、その場合は再読込で初期値に戻ります。「初期値に戻す」で保存済み調整を解除できます。

全ゲーム設定は `js/config.js` に集約しています。座標と速度は1000×620の内部画面座標、時間は秒です。打上げ力は上向きの速度の大きさ、重力は下向きの加速度です。判定半径はボール半径を含めた中心の許容距離です。UIの保存済み設定はconfig.jsより優先されるため、コード変更後はパネルで初期値へ戻してください。

まず重力とFOOT打上げ力で滞空時間を決め、各部位の打上げ力、回転時間、判定半径の順に調整することを推奨します。パネルにない身体部位の高さ・横オフセット、初期投入、試合時間などもconfig.jsで変更できます。

## 構成と検証

- `index.html` / `style.css`: 画面・操作案内・調整パネル
- `js/config.js`: 全ゲームパラメータ
- `js/engine.js`: 物理、接触、状態、得点（描画と独立）
- `game.js`: 入力、アニメーション状態、音、画面更新、判定表示、2Dフォールバック
- `js/renderer3d.js`: 3D選手、左右の接触ポーズ、ボール、練習場、観客、照明
- `vendor/three.min.js`: 同梱Three.js r160（MITライセンス。THREE-LICENSE.txtを同梱）
- `tests/visual.html`: 左右の足・膝、頭、胸、空中ヘディング、回転の静止ポーズ検証
- `tests/engine.test.cjs`: 主要ルールの自動検証（実行は任意。Nodeがある場合に `node tests/engine.test.cjs`）

物理更新は120Hz固定、描画はrequestAnimationFrame。処理の長い停止後に一度に大量の物理更新を行わない構成です。低負荷の通常ブラウザ環境を想定し、極端な処理落ち時は実時間よりゲーム進行が遅くなる場合があります。

16項目の自動検証に合格。左右の足・膝が移動方向に依存せず選択されること、左右範囲外で空振りになること、左右切替とリセット、1滞空中の2回転を追加検証。4部位判定、ジャンプ単独で非接触、クリック付き空中ヘディング、MISSで軌道不変、自動打球なし、回転中打球不可、遅延ボーナス、初回前の回転無効、落球リセット、60秒終了、カウントダウン、連続技入力を検証しています。

連続技の検証は、初期状態からボール・選手をワープさせず、A/D相当の移動と打球・回転・ジャンプの入力だけで FOOT → KNEE → SPIN → CHEST → SPIN → FOOT → JUMP HEADER を成功させるシミュレーションです。人による原作同等の操作感の確認を代替するものではありません。

ブラウザでは起動、カウントダウン、時間経過、ジャンプ、F2判定表示、調整パネル、一時停止・再開を確認。検証用にループバックHTTPで表示しました。配布版は外部通信・モジュール・fetchを使わずライブラリも同梱しているため、通常のPCブラウザでファイル直接起動できる構造です。


追加ビジュアル参考: https://game-ac.com/free/sports/psg-soccer-freestyle/ とユーザー添付の画面。立体選手と奥行きの参考とし、街並み・タイミングゲージ・自動技のルールは採用していません。現段階のモデルはオリジナルのスタイライズされた3D試作で、人物スキャンや商用品質のリグモデルではありません。

3D表示にはWebGL対応ブラウザが必要です。PC性能によって描画速度は異なります。Three.jsはファイル直接起動との互換性のためr160のクラシックスクリプト版を同梱し、旧ビルド形式の非推奨警告が出る場合がありますが、外部通信や動作エラーではありません。
