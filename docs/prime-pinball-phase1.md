# PRIME PINBALL — Stadium / gameplay revision

既存の右サイドバー（PC・スマホ）から同じタブ内で開く独立ゲームです。本編は既存の一時停止処理で止め、戻った後にユーザーが再開します。

## サッカー台と手応え
- 既存同梱のThree.jsによる3Dキャビネット。芝、観客席、ミニチュアゴール、投光器、金属レール、厚みのあるバンパーとフリッパー。
- 光・接地影・環境反射。バンパーが打撃時に沈んで戻るアニメーション。描画はゲーム状態の読み取りのみ。
- 手続き生成の芝・盤面をキャッシュ。観客はインスタンス描画、スマホは解像度と影を抑制。追加の外部モデル・テクスチャのダウンロードなし。
- WebGL初期化ができない場合はCanvas描画へ切り替え。同じ物理・ルールで操作可能。
- 接触、フリッパー、バンパー、ゴールで効果音を分ける。音は初期OFF。

## 繰り返し遊ぶルール
1. Space / 発射ボタンを押して、離すと発射。長く押すほど強い発射。
2. 発射後の左上SKILLレーンへの下降通過で+1,000（各球1回、ボールセーブ再発射では再獲得不可）。弱い発射も試してください。
3. P・R・Mを揃えると+1,000、上のゴールを開放。
4. 上向きのシュートが開放中のゴールを通ると+2,000。以降のゴールは500ずつ増加し、最大+5,000。
5. ゴール後15秒間はPOWER PLAY。バンパー100→300、ターゲット200→600。スリング50、セット完成ボーナス1,000は変化なし。
6. 3球制。発射後4秒は落球を救済。落球後もターゲット・ゴール開放の進行は残り、POWER PLAYは終了。
7. 終了後にスコア、ゴール数、スキルショット数、フリッパーヒット数を表示。すぐ再挑戦できる。

自己ベストは `prime.pinball.best.v1` という独立したlocalStorageキーで、この端末・ブラウザだけに保存します。名前入力・オンラインランキング・報酬はありません。保存不可でもプレイは継続します。

## 操作
- PC：A / ← が左、D / → が右、Space長押し→離して発射、Escで一時停止。
- スマホ：左右FLIPは同時押し可能。発射ボタン長押し→離して発射。
- 一時停止・画面非表示・フォーカス移動・タッチキャンセル時は入力と発射チャージを解除。

## 本編の保護
変更は新規ピンボールの物理・表示・音・入力・端末内記録と入口の読み込みのみ。本編の `game.js`、リフティング物理・入力・採点・称号・ランキング・デイリー、Supabase、Workerには変更なし。
BOOSTの付与・消費・DB接続は未実装。新しいホームやステージ選択はなし。PRはユーザー確認までマージしません。

## 検証
- `npm test` 成功。ピンボール13件と既存一式。発射・反射・落球・セーブ・スキルショット・ゴール・倍率終了・多重加点防止・決定性・速度上限・再挑戦を確認。
- `npm run build` 成功。
- ローカルEdge：PC 1440×900、スマホエミュレーション844×390 / 390×844。入口と戻る、一時停止/再開、画面比率、横はみ出し、入力解除を確認。
- 追加ブラウザ検証：チャージ発射、停止中の時計、ゴール→倍率、終了→端末内記録→再挑戦、チャージ中断、実際の2点タッチイベント、WebGL無効時の代替描画。
- ゴール/終了画面のテストは**テスト内だけ**で状態を用意し、その後の通常処理とUIを検証。自然なプレイの難易度を保証するものではありません。
- 複数のタイミングでフリッパーを操作するシミュレーションでゴールの到達性を確認。面白さ・音の気持ちよさ・長期リプレイ性はユーザーの実プレイで確認が必要。
- **本番ブラウザ・実機スマホ・実機FPS/電池消費は未確認。ローカル確認とCI成功は本番確認を意味しません。**

ブラウザ検証にはPlaywrightとEdge、ローカルHTTPサーバーが必要です。`scripts/pinball-smoke.cjs` と `scripts/pinball-interaction-smoke.cjs` を実行します。`PINBALL_BASE_URL`（既定8781）、`PINBALL_SCREENSHOTS`（既定OS一時フォルダ）で指定可能です。
